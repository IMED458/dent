# სტომატოლოგიური კლინიკა — ელექტრონული სამედიცინო ბარათი

React + Vite + Express აპლიკაცია, მზადაა Google AI Studio-სთვის (Build → Import from GitHub ან ZIP).

## გაშვება

```bash
npm install
npm run dev      # http://localhost:3000
```

პროდაქშენი: `npm run build && npm start`.

AI-ით ტექსტის დახვეწის ფუნქციისთვის AI Studio-ში დააყენეთ `GEMINI_API_KEY` (Secrets). გასაღების გარეშე პროგრამა სრულად მუშაობს, მხოლოდ ✨ ღილაკი გამოიტანს შეტყობინებას. Gemini-ზე იგზავნება მხოლოდ ერთი ველის ტექსტი, პაციენტის იდენტიფიკატორების გარეშე.

## მონაცემები

ყველა მონაცემი (პაციენტები, ვიზიტები, დოკუმენტები, რენტგენის სურათები) ინახება ბრაუზერის IndexedDB-ში. **რეგულარულად შექმენით სარეზერვო ასლი**: „პარამეტრები → მონაცემები“. სხვა კომპიუტერზე გადატანა — იმავე ფაილის აღდგენით.

## ძირითადი პრინციპები

- **ერთი პაციენტი — ერთი ბარათი.** რეგისტრაციისას პირადი ნომერი (11 ციფრი) ან პასპორტი მოწმდება; დუბლიკატი ვერ შეიქმნება — გამოჩნდება არსებული ბარათის გახსნის ღილაკი.
- **ბარათის (ისტორიის) ნომერი** ენიჭება ერთხელ (`წელი-რიგითი`, მაგ. `2026-0001`) და არასდროს იცვლება; ვიზიტები ბარათში ინომრება (№1, №2…).
- ყველა ფორმა იქმნება მხოლოდ კონკრეტული პაციენტის ბარათიდან და ავტომატურად ივსება მისი მონაცემებით — სხვა პაციენტთან აღრევა შეუძლებელია.
- ხელმოწერილი ვიზიტი/დოკუმენტი იბლოკება; შესწორება — დანართით ან ადმინისტრატორის განბლოკვით (მიზეზი იწერება აუდიტში).
- ყველა მოქმედება იწერება აუდიტის ჟურნალში (ვინ, როდის, რა).

## მოდულები

- მთავარი დაფა: პაციენტების ჩამონათვალი, ძებნა, დღევანდელი ჩაწერები, ხელმოუწერელი ჩანაწერები
- პაციენტის ბარათი: მიმოხილვა, ვიზიტები/დღიური, ოდონტოგრამა (FDI), რადიოლოგია (ფოტოს/რენტგენის ატვირთვა, ვიუერი), დოკუმენტები, ფინანსები, ცვლილებების ისტორია
- დოკუმენტები: ფორმა №IV-100/ა, ინფორმირებული თანხმობა (8 სახის მანიპულაცია), პერსონალური მონაცემების დამუშავების თანხმობა, უარი მომსახურებაზე, მიმართვა, ამონაწერი, ვიზიტის ცნობა, რენტგენოლოგიური ოქმი, მკურნალობის გეგმა/ხარჯთაღრიცხვა, თავისუფალი ფორმა
- ICD-10: K00–K14 და მომიჯნავე კოდები ქართული დასახელებით; კოდის აკრეფისას ტექსტი ავტომატურად ივსება; საკუთარი კოდების დამატება
- შაბლონები: ყველა ტექსტურ ველზე + ვიზიტის სრული შაბლონები (დიაგნოზი, მკურნალობა, რეკომენდაციები, მანიპულაციები)
- ჩაწერები/კალენდარი, დოკუმენტების სარეგისტრაციო ჟურნალი (CSV), პრეისკურანტი, თანამშრომლები და როლები (PIN-ით შესვლა, ავტომატური დაბლოკვა)
