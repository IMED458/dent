# სტომატოლოგიური კლინიკა — ელექტრონული სამედიცინო ბარათი

React + Vite + Express აპლიკაცია, მზადაა Google AI Studio-სთვის (Build → Import from GitHub ან ZIP).

## გაშვება

```bash
npm install
npm run dev      # http://localhost:3000
```

პროდაქშენი: `npm run build && npm start`.

AI-ით ტექსტის დახვეწის ფუნქციისთვის AI Studio-ში დააყენეთ `GEMINI_API_KEY` (Secrets). გასაღების გარეშე პროგრამა სრულად მუშაობს, მხოლოდ ✨ ღილაკი გამოიტანს შეტყობინებას. Gemini-ზე იგზავნება მხოლოდ ერთი ველის ტექსტი, პაციენტის იდენტიფიკატორების გარეშე.

## მონაცემები

ყველა მონაცემი (პაციენტები, ვიზიტები, დოკუმენტები, რენტგენის სურათები) ინახება ბრაუზერის IndexedDB-ში. **რეგულარულად შექმენით სარეზერვო ასლი**: „პარამეტრები → მონაცემები“. სხვა კომპიუტერზე გადატანა — იმავე ფაილის აღდგენით.

## სამართლებრივი საფუძველი

| ფორმა | დასახელება | საფუძველი |
|---|---|---|
| №IV-220/ა | სტომატოლოგიური პაციენტის სამედიცინო ბარათი | მინისტრის 25.11.2011 №01-55/ნ ბრძანება, დანართი №1 |
| №IV-220-1/ა | პაციენტის გასინჯვის ფურცელი | №01-55/ნ, დანართი №2 (ცვლ. №01-16/ნ, 26.02.2022 — ელ. რეცეპტის №) |
| №IV-220-2/ა | პაციენტის წერილობითი ინფორმირებული თანხმობა სამედიცინო მომსახურების გაწევაზე | №01-55/ნ, დანართი №3; „პაციენტის უფლებების შესახებ“ კანონი, მუხ. 22, 41 |
| №IV-220-3/ა | სტომატოლოგიური პაციენტის რეგისტრაციის ჟურნალი | №01-55/ნ, დანართი №4 |
| №IV-100/ა | ცნობა ჯანმრთელობის მდგომარეობის შესახებ | მინისტრის 09.08.2007 №338/ნ ბრძანება (ცვლ. 2008, 2013, 2020) |

- **ისტორიის ნომერი** ინომრება წლის მიხედვით: `1/26`, `2/26` … `1000/26`; ახალ წელს იწყება 1-დან. ენიჭება ერთხელ და აღარ იცვლება. პაციენტი იდენტიფიცირდება პირადი ნომრით — ერთ პირზე მეორე ბარათი ვერ გაიხსნება.
- **გასინჯვის ფურცელი (IV-220-1/ა)** იხსნება ყოველ ახალ შემთხვევაზე; პირველადი და ყველა განმეორებითი ვიზიტი ერთ ფურცელზეა, ბოლოს — ეპიკრიზი და რჩევა-დარიგება.
- **საბოლოო დიაგნოზი** — ICD-10 (მუხ. 3.2); ჩარევების კოდები — ჩანაწერის ბოლოს (მუხ. 3.3).
- **თანხმობა (IV-220-2/ა)** ივსება მომსახურებამდე; სავალდებულოა ქირურგიული ჩარევისას და არასრულწლოვანზე (მუხ. 22.2.ა, 22.3). 16 წლამდე ხელს აწერს მშობელი/კანონიერი წარმომადგენელი, 16+ — თავად პაციენტი (მუხ. 41).
- **IV-100/ა** — 20 პუნქტი; პირადი ნომერი ეთითება 16 წლიდან; გაიცემა მხოლოდ იმ დაავადებაზე, რომლითაც პაციენტმა მიმართა; აღირიცხება ჟურნალში რიგითი ნომრით; ხელს აწერს მკურნალი ექიმი და ხელმძღვანელი, ბეჭედი.
- დოკუმენტაცია იწარმოება სახელმწიფო ენაზე და ელექტრონულად (მუხ. 1.2). პაციენტს ეძლევა ნებისმიერი ფორმის ასლი (მუხ. 1.5).
- ხელმოწერილი ჩანაწერი იბლოკება; შესწორება — დანართით ან ადმინისტრატორის განბლოკვით (აუდიტში ჩაწერით).

## ფინანსები

- მომსახურების დამატება პრეისკურანტიდან (ერთდროულად რამდენიმე) — გადახდამდეც: **დაგეგმილი** (ბალანსში არ ირიცხება) ან **შესრულდა** (ირიცხება დავალიანებად); რაოდენობა, კბილი, ფასდაკლება %.
- ბალანსი = შესრულებული მომსახურება (+ ვიზიტებში შეტანილი მანიპულაციები) − გადახდები; ავანსის მიღებაც შესაძლებელია. თანხები მრგვალდება თეთრამდე.
- რენტგენის ატვირთვისას შესაბამისი მომსახურება ავტომატურად ირიცხება (შეიძლება შეცვლა/გამორთვა).
- ანგარიში/ხარჯთაღრიცხვა და გადახდის ქვითარი (ნაშთით) იბეჭდება.
- „პარამეტრები → სერვისები და ფასები“: დამატება, წაშლა, რედაქტირება ცხრილშივე, ფასების ცვლილება %-ით.

## მოდულები

- მთავარი დაფა: პაციენტების ჩამონათვალი, ძებნა, დღევანდელი ჩაწერები, ხელმოუწერელი ჩანაწერები
- პაციენტის ბარათი: მიმოხილვა, ვიზიტები/დღიური, ოდონტოგრამა (FDI), რადიოლოგია (ფოტოს/რენტგენის ატვირთვა, ვიუერი), დოკუმენტები, ფინანსები, ცვლილებების ისტორია
- დოკუმენტები: ფორმა №IV-100/ა, ინფორმირებული თანხმობა (8 სახის მანიპულაცია), პერსონალური მონაცემების დამუშავების თანხმობა, უარი მომსახურებაზე, მიმართვა, ამონაწერი, ვიზიტის ცნობა, რენტგენოლოგიური ოქმი, მკურნალობის გეგმა/ხარჯთაღრიცხვა, თავისუფალი ფორმა
- ICD-10: K00–K14 და მომიჯნავე კოდები ქართული დასახელებით; კოდის აკრეფისას ტექსტი ავტომატურად ივსება; საკუთარი კოდების დამატება
- შაბლონები: ყველა ტექსტურ ველზე + ვიზიტის სრული შაბლონები (დიაგნოზი, მკურნალობა, რეკომენდაციები, მანიპულაციები)
- ჩაწერები/კალენდარი, დოკუმენტების სარეგისტრაციო ჟურნალი (CSV), პრეისკურანტი, თანამშრომლები და როლები (PIN-ით შესვლა, ავტომატური დაბლოკვა)
